# Cycle 7: Feature Depth — Building Resource Production/Consumption

## Observed Problem
Buildings existed in the world (generated by `generate_cities`) but had empty `resourcesProduced`/`resourcesConsumed` fields. The `_process_resources` method only handled natural resource regrowth, not building production. Agents could `build` but buildings had no economic effect — no resource production, no consumption chains.

## Evidence
- 3 farms + 3 markets generated per world, all with `resourcesProduced=[]`, `resourcesConsumed=[]`
- `_process_resources` only handled natural resource regrowth (timer-based)
- `build` action emitted events but buildings were not added to world's `buildings` list
- No economic loop: gather → build → produce → consume

## Fix
1. **BUILDING_PRODUCTION mapping** at module level in `world_gen.py`:
   - FARM: produces FOOD, consumes WATER
   - LUMBER_CAMP: produces WOOD, consumes FOOD
   - MINE: produces IRON, consumes FOOD
   - WORKSHOP: produces WOOD, consumes IRON
   - QUARRY: produces STONE, consumes FOOD
   - MARKET: no production/consumption
   - BARRACKS/TEMPLE/PALACE: various

2. **Modified `generate_cities`** to return `(cities, all_buildings)` tuple and populate `resourcesProduced`/`resourcesConsumed`

3. **Extended `_process_resources`** in `core.py`:
   - Iterates all buildings each tick
   - Produces resources (increments resource amounts, emits `building_production` events)
   - Consumes resources (decrements resource amounts, emits `building_consumption` events)

4. **Added `_handle_building_production`** for replay compatibility (sets resource amount from event data)

5. **Updated `_handle_build`** to work with `world["buildings"]` list

## Verification
- All 30 tests pass (10 eat + 13 emergent + 2 market + 3 building + 2 social fragility)
- 3 new regression tests: `test_building_production_emits_events`, `test_buildings_have_production_consumption`, `test_building_production_replay`
- Manual verification: 3 farms produce food every tick, consume water
- Replay determinism preserved

## Files Changed
- simulation/core.py: building production in _process_resources, _handle_building_production, updated _handle_build
- simulation/world_gen.py: BUILDING_PRODUCTION mapping, generate_cities returns (cities, buildings), populated resourcesProduced/Consumed
- test_emergent_depth.py: 3 building production regression tests
